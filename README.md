# 🎧 Minhas Músicas

Player de música estilo Spotify para as suas músicas baixadas. Um único arquivo, sem instalação e sem internet.

## Como usar

1. Abra o `index.html` no navegador (Chrome, Edge ou Firefox).
2. Clique em **+ Adicionar músicas** (ou **📁 Pasta**) — ou arraste os arquivos para a janela.
3. Dê dois cliques numa música para tocar (no celular, um toque).

As músicas ficam salvas no navegador, então continuam lá quando você abrir de novo.

## Recursos

- Biblioteca com busca por título, artista ou álbum
- Lê título, artista, álbum e capa das tags do MP3 (ou usa o nome do arquivo `Artista - Música`)
- Curtidas 💚 e playlists (botão direito ou ⋯ numa música)
- Aleatório, repetir (tudo / uma), "tocar em seguida"
- Barra de progresso, volume, atalhos: `Espaço` toca/pausa, `Shift+→/←` próxima/anterior
- Controles de mídia do sistema (teclado multimídia, tela de bloqueio)
- Formatos: MP3, M4A, AAC, FLAC, OGG, OPUS, WAV
